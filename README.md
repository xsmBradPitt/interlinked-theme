# Interlinked — Blade Runner 2049 inspired

A dark teal terminal-glow theme for VS Code and Cursor, inspired by *Blade Runner 2049* and adapted
from the Zed theme by Takk8IS. Deep teal-black surfaces, glowing mint and aquamarine text, and amber
used sparingly as an accent.

## Install

- **VS Code** — search for "Interlinked" in the Extensions view, or install
  [`xsmbradpitt.interlinked-theme`](https://marketplace.visualstudio.com/items?itemName=xsmbradpitt.interlinked-theme)
  from the Visual Studio Marketplace.
- **Cursor** — Cursor installs extensions from Open VSX. Search for "Interlinked" in the Extensions
  panel, or open
  [`xsmbradpitt/interlinked-theme`](https://open-vsx.org/extension/xsmbradpitt/interlinked-theme).
- **Manually** — download the `.vsix` from
  [GitHub Releases](https://github.com/xsmBradPitt/interlinked-theme/releases), then run
  `Extensions: Install from VSIX...` from the Command Palette.

Then run `Preferences: Color Theme` and select **Interlinked**.

## What is covered

**Workbench and editor:** editor (gutter, bracket pair colorization, diagnostics, inlay hints,
sticky scroll), side bar, activity bar, status bar, title bar, tabs, panel, lists and trees,
inputs, dropdowns, checkboxes, buttons, quick input and the Command Palette, notifications,
peek view, minimap, scrollbar, breadcrumbs, hover / suggest / find widgets, badges and progress,
focus borders.

**Terminal and source control:** the integrated terminal with all 16 ANSI colours, Git
decorations, the diff editor and merge conflicts.

**Syntax:** TextMate scopes and semantic tokens, checked against TypeScript/JavaScript, C#,
Kotlin, Java, HTML, CSS, SQL, Bash, JSON, YAML and Markdown.

Cursor's own UI picks the theme up wherever it uses standard workbench colour keys.

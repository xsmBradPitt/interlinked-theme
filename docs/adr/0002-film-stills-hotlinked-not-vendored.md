# 電影畫面採外連，不放進本 repo

上游 repo 的 `screenshot-03.jpg`、`screenshot-04.jpg` 是電影畫面或 Territory Studio 的 UI 設計稿，版權屬於片商與設計工作室，上游的 MIT 授權涵蓋不到。我們接受在 README 中當作「靈感來源」展示的風險，但只用外連方式連到上游 repo 的圖片網址，不把檔案複製進本 repo 或 `.vsix`；圖片只放在 README 底部，並附上版權說明。擴充套件頁面的圖示、galleryBanner 和主要截圖一律自製。

## Consequences

- DMCA 通知是針對整個擴充套件，不只是圖片；萬一收到，處理方式是刪掉 README 裡那幾行，然後發一個新版本。
- 上游如果刪掉圖片，README 會出現破圖，屆時直接刪除該段落即可。

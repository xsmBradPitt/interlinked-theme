# Reference Theme

`zed-blade-runner-2049.json` is copied verbatim from the upstream Zed theme
<https://github.com/Takk8IS/blade-runner-2049-theme-for-zed> (via the fork
xsmBradPitt/blade-runner-2049-theme-for-zed, commit 87321ef).

It is the colour specification Interlinked is derived from. It is not packaged
or published. To pick up upstream changes, sync the fork, copy the file here
again, and diff.
